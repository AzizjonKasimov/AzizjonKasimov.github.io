工作方式

AI 原生开发，辅以护栏

自 2026 年 4 月起，我的大部分软件都是通过指挥编程智能体（Claude Code 和 Codex）来构建的。智能体写得很快，而围绕它们的规则、项目笔记和检查保证了工作的可靠性。

私有仓库 · 2026

编程智能体的共享规则

一套集中管理的规则和项目笔记，用于 19 个项目（9 个公司项目，10 个个人项目）。Claude Code 和 Codex 加载相同的标准，并在会话之间保留上下文。如果无法加载规则，智能体必须停下来询问。

智能体保持小范围改动、更新文档，从不读取密钥，也从不修改生产数据库；任务必须通过真实的端到端检查才算完成。

私有仓库 · TypeScript · 2026

私有 AI 网关

一个由 Claude 驱动的小型服务，为我的应用提供统一的 AI 接口。它返回符合 JSON Schema 的输出，并接受 OpenAI 风格的请求，因此现有客户端无需修改即可使用。

它还能执行智能体回合：模型负责规划，调用方应用运行自己的工具，因此应用数据从不存放在网关上。
