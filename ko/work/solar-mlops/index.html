프로덕션 Recs Innovation · 2024

프로덕션 환경의 태양광 발전량 예측과 이상 탐지

Recs Innovation에서 인턴으로 시작해 두 차례 승진하여 AI Team Lead가 되었습니다. 태양광 발전량 예측과 태양광 발전소 이상 탐지를 프로덕션에 적용한 팀을 이끌었고, 추론 서비스는 가상발전소(VPP) 플랫폼에 연동되었습니다.

역할
Data Science Intern → AI Developer → AI Team Lead (2024년 3월–11월). ML, 백엔드, 프론트엔드 팀을 이끌었습니다.
결과
예측 오차 9%에서 7%로 감소. 이상 탐지 precision 약 35%, recall 약 37% 향상. 배포 시간 3시간에서 15분으로 단축.
기술 스택
PyTorch, 그래프 신경망(GNNAD), FastAPI, Docker Compose, GitHub Actions, PostgreSQL, Prometheus, Grafana, MLflow
비즈니스 효과
한국전력거래소(KPX) 전력 중개 수익. 수동 운영 업무 80% 감소(연 약 48,000달러).

문제

회사에는 실험 단계를 넘어 프로덕션에서 작동하는 모델 두 가지가 필요했습니다.

  • 한국전력거래소(KPX)의 전력 중개에 쓸 수 있을 만큼 정확한 태양광 발전량 예측
  • 태양광 발전소 데이터를 감시하는 이상 탐지

두 모델 모두 안정적으로 실행되고 상용 VPP 플랫폼에 연동되어야 했습니다.

시스템 개요

발전량 예측

  • AI Developer로서 평균 오차 10% 미만의 PyTorch 태양광 발전량 예측 모델을 만들었습니다. 이 결과로 회사는 KPX 사업 참여 자격을 얻었습니다.
  • 팀 리더로서 예측 오차를 9%에서 7%로 줄였고(22% 감소), 이를 통해 KPX 전력 중개 수익이 가능해졌습니다.

태양광 발전소 이상 탐지

그래프 기반 모델(GNNAD)을 사용한 다변량 시계열 이상 탐지를 맡았습니다. 성능은 단계적으로 향상되었습니다.

  • 오류를 더 명확하게. 오픈소스 코드베이스를 대폭 리팩터링하고, 모든 피처에 대해 예측값과 실제 데이터를 비교하는 그래프를 추가했습니다.
  • 오차 계산 개선: precision +5%, recall +7%.
  • 시간대별 임계값: 하루 동안의 오차 변화를 반영하기 위해 하나의 전역 임계값 대신 24개의 임계값을 사용했습니다. Recall +10%.
  • 더 깨끗한 학습 데이터: 학습 데이터에서 이상값을 제거해 precision +30%, recall +20%를 얻었습니다.
  • 현실적인 검증: 16포인트 추론 윈도우, 시간대별 임계값, 매일 밤 재학습 등 프로덕션과 같은 조건의 교차 검증.

전체적으로 precision은 약 35%, recall은 약 37% 향상되었습니다. 그전에 인턴으로서 GNN 모델을 precision 70%, recall 50%까지 튜닝하고, MLflow로 실험을 추적했으며, 이상 탐지 시스템을 VPP 플랫폼에 연결하는 FastAPI 엔드포인트를 만들었습니다.

MLOps와 배포

  • 이상 탐지 시스템을 컨테이너화하고 GitHub Actions로 배포를 자동화했습니다. 배포 시간이 3시간에서 15분으로 줄었습니다.
  • Docker Compose, GitHub Actions, PostgreSQL, Prometheus, Grafana로 엔드투엔드 MLOps 인프라를 구축했습니다. 수동 운영이 80% 줄어 연간 약 48,000달러를 절감했습니다.

팀 리딩

AI Team Lead로서 ML, 백엔드, 프론트엔드 팀을 관리하고, 모델이 VPP 플랫폼에 문제없이 연동되도록 했습니다.

결과

  • 9% → 7%예측 오차, KPX 전력 중개 수익의 기반
  • +35% / +37%이상 탐지 precision / recall
  • 3시간 → 15분배포 시간
  • −80%수동 운영 업무(연 약 48,000달러)
