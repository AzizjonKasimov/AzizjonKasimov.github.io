프로덕션 G-Man Auto Parts · 2025–2026

자동차 부품 AI 의미 검색

구매자와 공급업체는 여러 언어의 평범한 단어만으로 특정 차량에 맞는 정확한 부품을 찾을 수 있어야 했습니다. 저는 검색을 처음부터 끝까지 구축했고, 95% 정확도 기준을 충족한다는 것을 입증한 테스트 스위트도 만들었습니다.

역할
유일한 AI/ML 엔지니어. 설계, 임베딩, 개체명 인식, LLM 단계, 평가, 프로덕션 운영을 맡았습니다.
결과
필수 3,000개 부품 테스트에서 95% 이상 정확도. R&D 과제가 승인되었습니다.
기술 스택
Python, Django REST Framework, Weaviate, spaCy, OpenAI API (GPT-4o-mini), Celery, PostgreSQL, AWS S3, React
규모
200만 건 이상의 부품 레코드 카탈로그와 30만 개 이상의 검색 가능한 매물 (Kia, Hyundai, SsangYong, Chevrolet)

문제

사람들은 같은 부품을 여러 방식으로 부릅니다. “headlight”나 “head lamp”처럼 표현이 다르기도 하고, 비공식 명칭이나 다른 언어를 쓰기도 합니다. 하지만 정답은 정확히 한 차량에 맞는 하나의 부품 번호입니다. 브랜드, 모델, 연식, 연료, 변속기, 세대, 위치(좌/우, 앞/뒤)가 모두 맞아야 합니다.

경직된 키워드 필터로는 이를 처리할 수 없었습니다. 회사에는 올바른 부품을 높은 정밀도로 찾아 주는 자연어 검색이 필요했고, R&D 과제를 위한 공식 정확도 테스트도 통과해야 했습니다.

검색 요청 처리 흐름

구축한 내용

  • 벡터 검색 핵심. 부품 카탈로그를 Weaviate에 임베딩하고 Django REST Framework로 검색 서비스를 만들었습니다. recall을 높이기 위해 임베딩할 텍스트(필드 라벨, 부품 위치, 차량 연식, 선별한 동의어)를 직접 설계했습니다.
  • 개체를 엄격한 필터로. spaCy가 자유 형식 질의에서 구조화된 정보를 뽑아 정확한 필터로 바꿉니다. 표현의 차이는 벡터 검색이 처리하고, 차량과 위치가 맞는지는 필터가 보장합니다.
  • 두 가지 검색 모드. 구매자를 위한 상품 검색과 공급업체를 위한 자동 매칭입니다. 자동 매칭은 업로드된 부품을 카탈로그 레코드와 연결하고, 서로 다른 부품 번호마다 별도의 결과를 만듭니다.
  • 다국어 질의. 영어가 아닌 질의는 LLM 단계를 거칩니다. GPT-3.5-Turbo에서 GPT-4o-mini로 바꿔 더 낮은 비용으로 더 좋은 품질을 얻었고, 언어 확인 단계로 LLM 호출을 최소화했습니다.
  • 관련성 튜닝. LLM 재정렬기가 명백히 틀린 결과를 제거합니다. 부품명 별칭 시스템(예: “headlight” → “Head Lamp Assembly”)으로 일상적인 표현의 정확도를 높였습니다.
  • 프론트엔드 연동. React/TypeScript 스토어와 관리자 도구를 검색 API에 연결했습니다. 필터가 질의에 반영되고, 매칭 결과가 입력 폼을 자동으로 채우며, 결과는 확신도 임계값과 함께 관련성 순으로 정렬됩니다.

정확도 측정

정확도는 추측이 아니라 측정해야 했습니다. 프로덕션 검색과 같은 파이프라인을 선별된 고정 테스트 세트로 실행하는 내부 테스트 페이지를 만들었습니다.

  • 지표: accuracy@1, accuracy@3, precision, recall, F1, 혼동 행렬, 교차 검증.
  • 반복 가능한 실행: 자동 또는 수동으로 실행합니다. 실행마다 실행한 사람과 LLM 전처리 사용 여부를 기록합니다.
  • 안전한 설계: 테스트 데이터는 별도 컬렉션에 두고, 테스트가 프로덕션 데이터에 절대 접근하지 못하도록 보호 장치를 두었습니다.
  • 오류 분석: “결과 없음” 사례의 원인을 오래된 테스트 객체, SKU와 카탈로그 불일치, 충돌하는 개체 패턴, 차체 색상 처리에서 찾아 하나씩 해결했습니다.

결과

  • 95%+필수 3,000개 부품 평가 세트의 정확도
  • 승인정확도 기준을 통과한 R&D 과제
  • 30만+검색 가능한 매물 (200만 건 이상의 부품 레코드 카탈로그 기반)

검색은 구매자와 공급업체 모두를 위해 프로덕션에 출시되었습니다. 프로덕션에서도 자동 정확도 테스트를 실행하고, 발견된 문제를 해결했습니다.
