프로덕션 Recs Innovation · 2024

프로덕션 환경의 태양광 발전량 예측과 이상 탐지

두 가지 모델을 프로덕션에 올린 팀을 이끌었습니다. 하나는 태양광 발전소가 전력을 얼마나 생산할지 예측하고, 다른 하나는 발전소 데이터에서 평소와 다른 측정값을 찾아냅니다. 두 모델 모두 여러 발전소를 하나처럼 묶어 운영하는 플랫폼인 가상발전소(VPP)에 연동되었습니다.

G-Man Auto Parts의 다른 작업

  • 중고 부품 가격 예측

    감가상각, 수요, 실시간 시장 신호로 중고 부품의 가격을 매기는 모델을 연구했습니다. 실제 가격으로 이루어진 작은 테스트 세트에서 MAE와 MAPE로 측정한 정확도는 약 70–80%였습니다.

  • 이중 언어 상품 요약

    회사의 약 4만 개 상품 하나하나에 영어 요약과 한국어 요약을 써 주는 LLM 파이프라인을 만들었습니다. 요약은 부품 전문가들이 정한 규칙을 따랐습니다. 이 파이프라인은 개념 검증(PoC) 단계에 머물렀습니다.

  • 대규모 데이터 마이그레이션

    회사 레코드 약 4만 건을 새 데이터베이스로 옮기고, 외부 카탈로그 레코드 200만 건 이상을 적재했습니다. 중복은 제거했고, 각 배치는 원자적으로 썼기 때문에 실패해도 데이터가 반쯤 쓰인 채로 남을 수 없었습니다.
