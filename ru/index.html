Как я работаю

ИИ-нативная разработка с защитными механизмами

С апреля 2026 года я разрабатываю большую часть ПО, направляя кодинг-агентов: Claude Code и Codex. Агенты пишут быстро, а правила, заметки по проектам и проверки вокруг них делают работу надёжной.

Закрытый репозиторий · 2026

Общие правила для кодинг-агентов

Единый набор правил и заметок по проектам, который используется в 19 проектах (9 рабочих, 10 личных). Claude Code и Codex загружают одни и те же стандарты и сохраняют контекст между сессиями. Если правила не удаётся загрузить, агент должен остановиться и спросить.

Агенты вносят небольшие изменения, обновляют документацию, никогда не читают секреты и не меняют продакшен-базы данных. Задача считается выполненной, только когда пройдена реальная сквозная (end-to-end) проверка.

Закрытый репозиторий · TypeScript · 2026

Приватный ИИ-шлюз

Небольшой сервис на базе Claude, который даёт моим приложениям единую точку доступа к ИИ. Он возвращает ответы, соответствующие JSON Schema, и принимает запросы в формате OpenAI, поэтому существующие клиенты работают без изменений.

Кроме того, он выполняет шаги агента, в которых модель планирует, а вызывающее приложение само запускает свои инструменты, поэтому данные приложений никогда не хранятся на шлюзе.
