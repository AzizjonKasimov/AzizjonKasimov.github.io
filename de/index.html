Arbeitsweise

KI-natives Engineering mit Leitplanken

Seit April 2026 entwickle ich die meiste Software, indem ich Coding-Agenten anleite: Claude Code und Codex. Die Agenten schreiben schnell. Die Regeln, Projektnotizen und Prüfungen um sie herum halten die Arbeit verlässlich.

Privates Repo · 2026

Gemeinsame Regeln für Coding-Agenten

Ein zentrales Regelwerk mit Projektnotizen, genutzt in 19 Projekten (9 beruflich, 10 privat). Claude Code und Codex laden dieselben Standards und behalten den Kontext über Sitzungen hinweg. Lassen sich die Regeln nicht laden, muss der Agent anhalten und nachfragen.

Agenten halten Änderungen klein, pflegen die Dokumentation, lesen nie Secrets, ändern nie Produktionsdatenbanken und müssen einen echten End-to-End-Test bestehen, bevor eine Aufgabe als erledigt gilt.

Privates Repo · TypeScript · 2026

Privates KI-Gateway

Ein kleiner Dienst auf Basis von Claude, der meinen Apps einen einzigen KI-Endpunkt bietet. Er liefert Ausgaben, die einem JSON Schema entsprechen, und nimmt Anfragen im OpenAI-Format an, sodass bestehende Clients unverändert funktionieren.

Außerdem steuert er Agentenabläufe, in denen das Modell plant und die aufrufende App ihre eigenen Tools ausführt. So liegen App-Daten nie auf dem Gateway.
