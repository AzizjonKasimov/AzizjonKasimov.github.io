Production G-Man Auto Parts · 2026

Serverless data pipeline on AWS

Pricing research needed a daily feed of used-parts listings from the market. I built an event-driven pipeline: on a schedule, Lambda workers take jobs from an SQS queue and save the listings to PostgreSQL, and CloudWatch raises an alarm when something fails.

It reached its target of 5M listings a day in testing, on the smallest database instance. In production, the source's rate limits held it to about 5,000 a day.

Production Recs Innovation · 2024

Solar forecasting and anomaly detection, in production

I led the team that put two models into production: one forecasts how much power a solar plant will make, and one flags unusual readings in the plant's data. Both fed a Virtual Power Plant, a platform that runs many plants together as one.

Forecast error fell from 9% to 7%, enough to sell power on the Korea Power Exchange. The detector's precision rose 35 points and its recall 37. A deploy took 15 minutes instead of 3 hours.

How I build

AI-native engineering, with guardrails

Since April 2026 I write most software by directing coding agents, Claude Code and Codex. The agents are fast. The rules, project notes, and checks I put around them keep the work reliable.

Private repo · 2026

Shared rules for coding agents

I keep one central set of rules and project notes, and 19 projects load it: 9 at work and 10 personal. Claude Code and Codex read the same standards and pick up the context of earlier sessions. An agent that cannot load the rules must stop and ask.

The rules make agents keep changes small, update the docs, and never read secrets or touch production databases. A task counts as done only after a real end-to-end check passes.

Private repo · TypeScript · 2026

Private AI gateway

A small service, backed by Claude, that gives all my apps one AI endpoint. It accepts OpenAI-style requests, so existing clients work unchanged, and it returns output that matches a JSON Schema.

It can also run an agent loop: the model decides which tool to call, but the calling app runs the tool itself, so app data never reaches the gateway.
