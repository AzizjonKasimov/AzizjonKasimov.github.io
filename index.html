How I build

AI-native engineering, with guardrails

Since April 2026, I build most software by directing coding agents: Claude Code and Codex. The agents write fast. The rules, project notes, and checks around them keep the work reliable.

Private repo · 2026

Shared rules for coding agents

One central set of rules and project notes, used in 19 projects (9 company, 10 personal). Claude Code and Codex load the same standards and keep context between sessions. If the rules can't be loaded, the agent must stop and ask.

Agents keep changes small, update the docs, never read secrets or change production databases, and must pass a real end-to-end check before a task counts as done.

Private repo · TypeScript · 2026

Private AI gateway

A small service, backed by Claude, that gives my apps one AI endpoint. It returns output that matches a JSON Schema and accepts OpenAI-style requests, so existing clients work unchanged.

It also runs agent turns where the model plans and the calling app runs its own tools, so app data never lives on the gateway.
